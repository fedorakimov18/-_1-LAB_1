## Содержание работы

Разработан визуальный алгоритм в среде **Scratch 3 (VM 3.32.1)** для решения **Задачи 3**:

> За один цикл вычислить значение функции `F(n) = 1!·2!·3!·…·n!`, где `n! = 1·2·3·…·n`.

### Идея решения (один цикл)
Вложенный цикл не нужен: факториал накапливается вместе с произведением.

```
i = 0;  p = 1;  F = 1
повторить n раз:
    i = i + 1
    p = p * i      // p хранит текущий i!
    F = F * p      // F накапливает произведение факториалов
вывести F
```

Сложность — O(n), тело цикла выполняется ровно `n` раз.

### Переменные проекта
| Переменная | Назначение |
|---|---|
| `n` | введённое пользователем число |
| `i` | номер текущего шага цикла |
| `p` | текущее значение `i!` |
| `F` | накопленное произведение `1!·2!·…·i!` |

### Состав блоков алгоритма
- `когда флажок нажат` — старт программы;
- `спросить «Введите n» и ждать` + `ответ` — ввод данных;
- `задать n / i / p / F` — инициализация;
- `повторить n раз` — единственный цикл;
- `изменить i на 1`, `задать p = p * i`, `задать F = F * p` — вычисления;
- `следующий костюм`, `повернуть на 24 градуса`, `изменить y на 6/-6`, `ждать 0.4 сек`, `говорить (объединить …)` — **анимация спрайта** и пошаговая визуализация значений;
- `говорить «Ответ: F(n) = F» 5 секунд`, `остановить всё` — вывод результата.

На сцене включены **мониторы (окна)** переменных `n`, `i`, `p`, `F` — по ним видно работу алгоритма на каждом шаге.
